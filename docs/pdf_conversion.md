# Процесс конвертации в PDF

TerraData использует сложный подход «человека посередине» (man-in-the-middle) для генерации официальных PDF из XML-данных.

## Рабочий процесс

Поскольку Росреестр не предоставляет прямого API для конвертации XML в PDF, TerraData имитирует поведение официального Личного Кабинета (ЛК):

1. **Загрузка**: XML отправляется на `/check-doc/uploadFile`.
2. **Валидация**: Система инициирует `/check-doc/check` для проверки документа.
3. **Рендеринг**: После валидации документ становится доступен в виде HTML-страницы по адресу `/check-doc/view/{guid}`.
4. **Конверсия**: TerraData извлекает этот HTML и с помощью `pdfkit` (который является оберткой над `wkhtmltopdf`) рендерит PDF.

## Зависимости
Этот процесс требует наличия `wkhtmltopdf` в хост-системе. В Docker-версии эта зависимость предустановлена в образе.
