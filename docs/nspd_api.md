# Справочник API НСПД

Интеграция с Национальной системой пространственных данных (НСПД) для получения геометрии, кадастровой стоимости и детальных карточек объектов недвижимости.

## Общие сведения

Клиент `NspdClient` работает с API `https://nspd.gov.ru/api/geoportal` и определяет категорию объекта по идентификатору `categoryId`:

| Категория | `categoryId` | Описание |
| :--- | :--- | :--- |
| Земельный участок | `36368` | ЗУ |
| Здание / ОКС | `36369` | Здания и объекты капитального строительства |
| Помещение / квартира | `37163` | Помещения |

## Эндпоинты

| Эндпоинт | Метод | Описание |
| :--- | :--- | :--- |
| `/nspd/cadastral-price/{cad_num}` | `GET` | Кадастровая стоимость и базовые сведения об объекте |
| `/nspd/property/{cad_num}` | `GET` | Полный пакет данных (база + геометрия + карточки) |
| `/nspd/details/objects-list` | `GET` | Список объектов (помещений/машиномест) |
| `/nspd/details/land-links` | `GET` | Связанные земельные участки |
| `/nspd/details/build-parts` | `GET` | Части ОКС |
| `/nspd/details/permission-types` | `GET` | Виды разрешённого использования |

## `/nspd/property/{cad_num}`

Система автоматически определяет категорию объекта и собирает разные наборы данных:

- **Здания (ОКС)**: список помещений и машиномест, связанные земельные участки, части ОКС, виды разрешённого использования.
- **Земельные участки**: объекты на участке, ВРИ, части ЗУ, состав единого землепользования (ЕЗП).
- **Помещения**: только базовые сведения и геометрия (детальные карточки для помещений недоступны).

Ответ для зданий и ЗУ содержит:
- `base_info` — базовые сведения и кадастровая стоимость;
- `geometry` — нормализованная геометрия (см. ниже);
- `details` — детальные карточки (набор зависит от категории).

## Детальные карточки (`/nspd/details/*`)

Эндпоинты для точечного запроса отдельных вкладок. Параметры:

| Параметр | Тип | Описание |
| :--- | :--- | :--- |
| `objdocId` | `int` | ID объекта (обязательный) |
| `registersId` | `int` | ID реестровой записи (необязательный) |
| `categoryId` | `int` | Категория объекта, по умолчанию `36369` (здания) |

Если `registersId` передан — запрос идёт по связке `objdocId + registersId`, иначе по `categoryId + geomId`.

## Геометрия и координаты

Все координаты в ответе возвращаются в стандартном формате **WGS 84 (EPSG:4326)**, готовом для отображения на картах (Leaflet, OSM). Конвертация из проекции Web Mercator (EPSG:3857) выполняется модулем `CoordsConverter`.
