# Справочник API Конвертера

Эндпоинты для сервисов трансформации документов.

## Конвертация XML в PDF
`POST /converter/xml-to-pdf`

Конвертирует XML-выписку Росреестра в отформатированный PDF-документ.

**Запрос:**
- `file` (multipart/form-data): `.xml` файл.

**Ошибки:**
- `400` — если загруженный файл не является XML-документом (проверяется расширение `.xml`).
- `500` — если конвертация завершилась ошибкой.

**Детальный процесс:**
1. **Загрузка**: XML отправляется на эндпоинт `uploadFile` ЛК Росреестра.
2. **Капча**: Система решает капчу, необходимую для загрузки.
3. **Проверка**: Документ отправляется на «проверку» (`check`), что инициирует внутреннюю трансформацию Росреестра в HTML.
4. **Получение**: Система извлекает сгенерированный HTML-контент.
5. **Рендеринг**: `pdfkit` конвертирует HTML в байтовый поток PDF.
6. **Очистка**: Временный документ удаляется на стороне Росреестра.

**Ответ:**
- `application/pdf`: Сгенерированный PDF-файл.
