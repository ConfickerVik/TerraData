# Быстрый старт

Запустите TerraData за несколько минут.

## 1. Запуск сервера
Если вы используете Docker:
```bash
docker-compose up
```
Или локально:
```bash
python main.py
```

## 2. Доступ к документации API
Откройте браузер и перейдите по адресу:
`http://localhost:8000/docs`

Вы увидите интерактивный интерфейс Swagger UI, где можно протестировать все эндпоинты.

## 3. Первые запросы

### Получение информации об объекте
1. Перейдите к `/rosreestr/info/{cad_num}`.
2. Введите действительный кадастровый номер (например, `34:11:090001:671`).
3. Выполните запрос.

### Конвертация XML в PDF
1. Перейдите к `/converter/xml-to-pdf`.
2. Загрузите `.xml` файл (пример доступен в папке `/data`).
3. Выполните запрос и скачайте полученный PDF.
