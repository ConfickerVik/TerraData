# Быстрый старт

Запустите TerraData за несколько минут.

## 1. Запуск сервера
Если вы используете Docker:
```bash
docker compose up --build
```
Или локально:
```bash
python main.py
```

## 2. Доступ к документации API
Откройте браузер и перейдите по адресу:
`http://localhost:8000/docs`

Вы увидите интерактивный интерфейс Swagger UI, где можно протестировать все эндпоинты.

## 3. Первые запросы

### Получение информации об объекте (Росреестр)
1. Перейдите к `/rosreestr/info/{cad_num}`.
2. Введите действительный кадастровый номер (например, `34:11:090001:671`).
3. Выполните запрос.

### Поиск по адресу (Росреестр)
Перейдите к `/rosreestr/search-address` и передайте параметр `address` с полным адресом.

### Кадастровая стоимость (НСПД)
Перейдите к `/nspd/cadastral-price/{cad_num}` и укажите кадастровый номер.

### Поиск адреса в ФИАС
Перейдите к `/fias/search-address` и передайте параметр `address` — получите список подсказок с ObjectID.

### Определение судебного участка (СУДРФ)
Перейдите к `/sudrf/by-cadastral` и укажите кадастровый номер — система вернёт судебный участок.

### Конвертация XML в PDF
1. Перейдите к `/converter/xml-to-pdf`.
2. Загрузите `.xml` файл (пример выписки доступен в `tests/mocks/sample_extract.xml`).
3. Выполните запрос и скачайте полученный PDF.

## 4. Тестирование
Запуск тестов:
```bash
pytest
```
