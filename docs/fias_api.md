# Справочник API ФИАС

Интеграция с Федеральной информационной адресной системой (ФИАС) для поиска адресов, получения ObjectID и детальных сведений об объектах.

## Общие сведения

Клиент `FIASClient` взаимодействует с двумя конечными точками ФНС:
- `https://fias.nalog.ru` — поиск по кадастровому номеру и получение мастер-токена;
- `https://fias-public-service.nalog.ru/api/spas/v2.0` — публичный API подсказок и детальных сведений.

Для доступа к публичному API используется мастер-токен, получаемый автоматически через `GetSpasSettings`.

## Эндпоинты

| Эндпоинт | Метод | Описание |
| :--- | :--- | :--- |
| `/fias/by-cadastral/{cad_num}` | `GET` | Сведения ФИАС по кадастровому номеру |
| `/fias/search-address` | `GET` | Подсказки вариантов адреса |
| `/fias/by-object-id/{object_id}` | `GET` | Детальные сведения по ObjectID |
| `/fias/object-id/{cad_num}` | `GET` | Получение ObjectID по кадастровому номеру |

## Параметры

Общий параметр `address_type` (для эндпоинтов, которые его принимают):

| Значение | Описание |
| :--- | :--- |
| `1` | Административное деление (по умолчанию) |
| `2` | Муниципальное деление |

## Описание эндпоинтов

### `/fias/by-cadastral/{cad_num}`
Возвращает детальные сведения ФИАС по кадастровому номеру. Внутренне сначала получает ObjectID (`GetObjectsByCadastralNumber`), затем запрашивает сведения по этому ID.

### `/fias/search-address`
Возвращает список кандидатов-подсказок с полями:
- `object_id` — внутренний ID ФИАС;
- `value` — полное текстовое представление адреса;
- `path` — путь в иерархии адреса.

Перед запросом адрес очищается через `AddressCleaner` (удаляются квартиры, помещения и служебные пометки).

### `/fias/by-object-id/{object_id}`
Возвращает детальную информацию об объекте ФИАС по его ObjectID (полученному, например, из подсказок или `/fias/object-id/`).

### `/fias/object-id/{cad_num}`
Возвращает только внутренний ObjectID ФИАС по кадастровому номеру:
```json
{ "object_id": "..." }
```

## Очистка адресов

Модуль `AddressCleaner` нормализует адресные строки перед поиском: убирает квартиры, помещения, литералы, внутригородские районы, строительные пометки и прочие элементы, мешающие поиску по дому в реестрах.
