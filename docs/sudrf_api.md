# Справочник API СУДРФ

Интеграция с ГАС «Правосудие» (sudrf.ru) для определения судебного участка по адресу, кадастровому номеру или ObjectID ФИАС.

## Общие сведения

Клиент `SudrfClient` взаимодействует с API `https://sudrf.ru/api.php` и сервисом подсказок `https://sudrf.ru/suggestions/api/4_1/rs/suggest/address`.

Определение судебного участка строится как цепочка источников (см. [Архитектура](./architecture.md)):

1. Из ФИАС по кадастровому номеру/адресу извлекается иерархия адреса, из которой берётся GUID дома.
2. По GUID через СУДРФ (`getCourtListByFiasCode`) определяется судебный участок.
3. Если GUID не найден — fallback: адрес очищается (`AddressCleaner`) и ищется в подсказках СУДРФ, откуда извлекается `fias_id` для повторного запроса.

## Эндпоинты

| Эндпоинт | Метод | Описание |
| :--- | :--- | :--- |
| `/sudrf/by-cadastral` | `GET` | Судебный участок по кадастровому номеру |
| `/sudrf/by-address` | `GET` | Судебный участок по адресу |
| `/sudrf/by-object-id` | `GET` | Судебный участок по ObjectID ФИАС |
| `/sudrf/by-fias` | `GET` | Список судов по FIAS ID (GUID) |

## Параметры

| Параметр | Тип | Описание |
| :--- | :--- | :--- |
| `cad_num` | `string` | Кадастровый номер (для `/sudrf/by-cadastral`) |
| `address` | `string` | Адрес (для `/sudrf/by-address`) |
| `object_id` | `string` | ObjectID ФИАС (для `/sudrf/by-object-id`) |
| `fias_id` | `string` | FIAS ID (GUID) (для `/sudrf/by-fias`) |
| `address_type` | `int` | Тип адресации ФИАС: `1` — административное (по умолчанию), `2` — муниципальное |

## Описание эндпоинтов

### `/sudrf/by-fias`
Прямой запрос к СУДРФ: `FIAS ID (GUID) → СУДРФ → Список судов`. Возвращает `{ "courts": [...] }`.

### `/sudrf/by-cadastral`
Полный цикл: `Кадастровый номер → ФИАС GUID → СУДРФ → Суд`. Возвращает `{ "court_info": ... }`.

### `/sudrf/by-address`
Полный цикл: `Адрес → ФИАС GUID → СУДРФ → Суд`. Возвращает `{ "court_info": ... }`.

### `/sudrf/by-object-id`
Полный цикл: `ObjectID → данные ФИАС → СУДРФ → Суд`. Возвращает и данные ФИАС, и сведения о суде:
```json
{
  "fias_data": { ... },
  "court_info": { ... }
}
```

## Формат `court_info`

Сведения о судебном участке:
- `court_name` — наименование суда;
- `vncod` — код судебного участка;
- `all_region_courts` — все суды региона (словарь `код → наименование`).
