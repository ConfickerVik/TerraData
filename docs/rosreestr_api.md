# Справочник API

В данном разделе описаны все доступные эндпоинты системы.

## 1. Данные Росреестра
Эндпоинты для получения общей информации и поиска объектов.

| Эндпоинт | Метод | Описание |
| :--- | :--- | :--- |
| `/rosreestr/info/{cad_num}` | `GET` | Полная информация по кадастровому номеру |
| `/rosreestr/search-address` | `GET` | Поиск кадастровых номеров по адресу |

## 2. Конвертер PDF
Сервис для генерации официальных документов.

| Эндпоинт | Метод | Описание |
| :--- | :--- | :--- |
| `/converter/xml-to-pdf` | `POST` | Конвертация XML-выписки в PDF |

## 3. Данные НСПД (Пространственные данные)
Интеграция с Национальной системой пространственных данных для получения геометрии и стоимости.

| Эндпоинт | Метод | Описание |
| :--- | :--- | :--- |
| `/nspd/cadastral-price/{cad_num}` | `GET` | Кадастровая стоимость и база |
| `/nspd/property/{cad_num}` | `GET` | Полный пакет данных (База + Геометрия + Карточки) |
| `/nspd/details/...` | `GET` | Точечные запросы детальных карточек |

**Особенности `/nspd/property/{cad_num}`:**
Система автоматически определяет категорию объекта и собирает разные наборы данных:
- **Здания**: Список помещений, связанные участки, части ОКС, ВРИ.
- **Земельные участки**: Объекты на участке, ВРИ, части ЗУ, состав ЕЗП.
- **Помещения**: Только базовые сведения.

Все координаты в ответе возвращаются в стандартном формате **WGS 84 (EPSG:4326)**, готовом для отображения на картах (Leaflet, OSM).
