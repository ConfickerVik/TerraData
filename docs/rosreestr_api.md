# Справочник API Росреестра

Эндпоинты для взаимодействия с сервисами данных Росреестра.

## Получение информации об объекте
`GET /rosreestr/info/{cad_num}`

Возвращает полные сырые JSON-данные по конкретному объекту.

**Параметры:**
- `cad_num` (path): Кадастровый номер объекта.

**Рабочий процесс:**
1. Клиент нормализует кадастровый номер.
2. Запрос отправляется в ЛК Росреестра.
3. Система автоматически решает капчу с помощью ML-модели.
4. Результат возвращается в формате JSON.

## Поиск по адресу
`GET /rosreestr/search-address`

Поиск кадастровых номеров на основе текстового адреса.

**Параметры:**
- `address` (query): Строка с полным адресом.

**Пример:**
`GET /rosreestr/search-address?address=г. Ростов-на-Дону, ул. Большая Садовая, д. 1`
