# Справочник API

В данном разделе описаны все доступные эндпоинты системы.

## 1. Данные Росреестра
Эндпоинты для получения общей информации и поиска объектов.

| Эндпоинт | Метод | Описание |
| :--- | :--- | :--- |
| `/rosreestr/info/{cad_num}` | `GET` | Полная информация по кадастровому номеру |
| `/rosreestr/search-address` | `GET` | Поиск кадастровых номеров по адресу |

## 2. Конвертер PDF
Сервис для генерации официальных документов.

| Эндпоинт | Метод | Описание |
| :--- | :--- | :--- |
| `/converter/xml-to-pdf` | `POST` | Конвертация XML-выписки в PDF |

## 3. Данные НСПД (Пространственные данные)
Интеграция с Национальной системой пространственных данных для получения геометрии и стоимости.

Подробное описание — см. [API НСПД](./nspd_api.md).

## 4. Данные ФИАС
Федеральная информационная адресная система: поиск адресов и сведений об объектах.

Подробное описание — см. [API ФИАС](./fias_api.md).

## 5. Данные СУДРФ (судебные участки)
Определение судебного участка по кадастровому номеру, адресу или ObjectID ФИАС.

Подробное описание — см. [API СУДРФ](./sudrf_api.md).
