# Добро пожаловать в документацию TerraData 🌍

TerraData — это API-сервис для автоматизации взаимодействия с государственными информационными системами: **Росреестром**, **НСПД**, **ФИАС** и **СУДРФ**.

## Обзор

Проект решает несколько основных задач:
1. **Извлечение данных**: Автоматизация получения информации об объектах недвижимости по кадастровым номерам и адресам (Росреестр, НСПД).
2. **Генерация документов**: Преобразование XML-выписок Росреестра в официальные PDF-документы.
3. **Пространственный анализ**: Обогащение данных точными координатами и полигонами через интеграцию с НСПД.
4. **Адресный поиск**: Работа с реестром ФИАС — поиск адресов, получение ObjectID и сведений об объектах.
5. **Определение подсудности**: Поиск судебного участка (СУДРФ) по адресу, кадастровому номеру или ObjectID ФИАС.
6. **Аутентификация и авторизация**: Регистрация/вход (JWT) и API-ключи, роли `admin`/`user`, суточные квоты запросов.

## Ключевые компоненты

- **Приложение FastAPI**: Обеспечивает высокопроизводительный REST API.
- **Клиент Росреестра**: Управляет HTTP-соединениями, сессиями и нормализацией запросов.
- **Клиент НСПД**: Интеграция с Национальной системой пространственных данных для получения геометрии и кадастровой стоимости.
- **Клиент ФИАС**: Поиск адресов и объектов в Федеральной информационной адресной системе.
- **Клиент СУДРФ**: Определение судебных участков через ГАС «Правосудие».
- **Конвертер координат**: Модуль перевода координат из проекции Web Mercator (EPSG:3857) в стандарт WGS 84 (EPSG:4326).
- **Очиститель адресов**: Нормализация адресных строк перед поиском в ФИАС и СУДРФ.
- **Решатель капчи**: Собственная OCR-модель на базе TensorFlow/Keras.
- **Конвертер PDF**: Координирует процесс загрузки XML, решения капчи и рендеринга HTML в PDF.
- **Модуль аутентификации**: JWT + API-ключи, роли, квоты (PostgreSQL, SQLAlchemy async, Alembic).
