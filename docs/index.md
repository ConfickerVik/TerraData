# Добро пожаловать в документацию TerraData 🌍

TerraData — это специализированный API для автоматизации взаимодействия с системами **Росреестра** (Федеральная служба государственной регистрации, кадастра и картографии).

## Обзор

Проект решает две основные задачи:
1. **Извлечение данных**: Автоматизация получения информации об объектах недвижимости с использованием кадастровых номеров и поиска по адресу.
2. **Генерация документов**: Преобразование XML-выписок, предоставляемых Росреестром, в официальные PDF-документы.

## Ключевые компоненты

- **Приложение FastAPI**: Обеспечивает высокопроизводительный REST API.
- **Клиент Росреестра**: Управляет HTTP-соединениями, сессиями и нормализацией запросов.
- **Решатель капчи**: Собственная OCR-модель на базе TensorFlow/Keras, которая считывает и решает защитные капчи в режиме реального времени.
- **Конвертер PDF**: Координирует процесс загрузки XML, решения капчи и рендеринга HTML в PDF с помощью `pdfkit`.
