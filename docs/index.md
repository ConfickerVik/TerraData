# Добро пожаловать в документацию TerraData 🌍

TerraData — это специализированный API для автоматизации взаимодействия с системами **Росреестра** и **НСПД**.

## Обзор

Проект решает три основные задачи:
1. **Извлечение данных**: Автоматизация получения информации об объектах недвижимости с использованием кадастровых номеров и поиска по адресу.
2. **Генерация документов**: Преобразование XML-выписок, предоставляемых Росреестром, в официальные PDF-документы.
3. **Пространственный анализ**: Обогащение данных точными координатами и полигонами через интеграцию с НСПД.

## Ключевые компоненты

- **Приложение FastAPI**: Обеспечивает высокопроизводительный REST API.
- **Клиент Росреестра**: Управляет HTTP-соединениями, сессиями и нормализацией запросов.
- **Клиент НСПД**: Интеграция с Национальной системой пространственных данных для получения геометрии.
- **Конвертер координат**: Модуль перевода координат из проекции Web Mercator (EPSG:3857) в стандарт WGS 84 (EPSG:4326).
- **Решатель капчи**: Собственная OCR-модель на базе TensorFlow/Keras.
- **Конвертер PDF**: Координирует процесс загрузки XML, решения капчи и рендеринга HTML в PDF.
