# Архитектура системы

TerraData спроектирован как модульный сервис с четким разделением между слоем API, слоем сервисов и ML-компонентами.

## Диаграмма компонентов

```text
[ Клиент ] <---> [ FastAPI API ] <---> [ Слой сервисов ] <---> [ Росреестр / НСПД / ФИАС / СУДРФ ]
                                              |
                                      [ ML Модель капчи ]
                                              |
                                      [ pdfkit / wkhtmltopdf ]
```

## Детальный анализ слоев

### 1. Слой API (`app/api/`)
Обрабатывает циклы HTTP-запросов и ответов. Использует модульные роутеры FastAPI для разделения логики:
- **Rosreestr API**: Данные об объектах и поиск.
- **NSPD API**: Пространственные данные и кадастровая стоимость.
- **FIAS API**: Поиск адресов и сведений ФИАС.
- **SUDRF API**: Определение судебных участков.
- **Converter API**: Генерация PDF-документов.

### 2. Слой сервисов (`app/services/`)
Содержит основную бизнес-логику:
- **RosreestrClient**: Управление сессиями, обход блокировок и автоматизация работы с ЛК Росреестра.
- **NspdClient**: Интеграция с API НСПД для извлечения геометрии и детальных карточек объектов.
- **FIASClient**: Взаимодействие с ФИАС — получение мастер-токена, поиск ObjectID по кадастровому номеру, подсказки адресов и детальные сведения об объектах.
- **SudrfClient**: Взаимодействие с sudrf.ru для определения судебного участка по FIAS GUID и fallback-поиск fias_id по адресу.
- **AddressCleaner**: Очистка и нормализация адресных строк (удаление квартир, помещений, служебных пометок) перед поиском в реестрах.
- **CoordsConverter**: Математический модуль для перевода координат из проекции Web Mercator (EPSG:3857) в WGS 84 (EPSG:4326) и расчета центроидов объектов.
- **RosreestrPdfConverter**: Оркестрация процесса XML $\rightarrow$ HTML $\rightarrow$ PDF.

### 3. ML Компонент (`app/models/`)
Модель на базе Keras (`pred.keras`), обученная для OCR (оптического распознавания символов) специально для капч Росреестра. Использует декодирование CTC (Connectionist Temporal Classification) для обработки текста переменной длины.

### 4. Внешние интеграции
- **ЛК Росреестра**: Источник данных и сервис трансформации XML.
- **API НСПД**: Источник пространственных данных и кадастровой стоимости.
- **ФИАС**: Федеральная информационная адресная система (fias.nalog.ru / fias-public-service.nalog.ru).
- **СУДРФ (sudrf.ru)**: Государственная автоматизированная система «Правосудие».
- **wkhtmltopdf**: Движок для рендеринга HTML в PDF.

## Связь между СУДРФ, ФИАС и кадастром

Определение судебного участка реализовано как цепочка источников:
1. По кадастровому номеру или адресу через ФИАС извлекается иерархия адреса, из которой берётся GUID дома.
2. По GUID через СУДРФ (`getCourtListByFiasCode`) определяется судебный участок.
3. Если GUID не найден — выполняется fallback: адрес очищается (`AddressCleaner`) и ищется в подсказках СУДРФ, откуда извлекается `fias_id` для повторного запроса.
