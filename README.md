# TerraData API 🌍

TerraData — это мощный API-сервис для взаимодействия с Федеральной службой государственной регистрации, кадастра и картографии (Росреестр). Он предоставляет возможности для извлечения информации об объектах недвижимости по кадастровым номерам, поиска объектов по адресу и конвертации XML-выписок Росреестра в официальные PDF-документы с использованием автоматического решения капчи.

## 🚀 Возможности

- **Получение информации об объекте**: получение полных сырых данных об объекте по его кадастровому номеру.
- **Поиск по адресу**: поиск кадастровых номеров на основе введенного адреса.
- **Конвертация XML в PDF**: загрузка XML-выписки и получение отформатированного PDF-документа.
- **Автоматическое решение капчи**: интегрированная OCR-модель на базе TensorFlow для автоматического распознавания капчи Росреестра.
- **Современный API**: построен на FastAPI для высокой производительности и автоматической генерации OpenAPI-документации.

## 🛠 Технологический стек

- **Язык**: Python 3.10+
- **Фреймворк**: [FastAPI](https://fastapi.tiangolo.com/)
- **OCR/ML**: [TensorFlow](https://www.tensorflow.org/) и [Keras](https://keras.io/)
- **HTTP-клиент**: [HTTPX](https://www.encode.io/httpx/)
- **Генерация PDF**: [pdfkit](https://pypi.org/project/pdfkit/) (требуется `wkhtmltopdf`)
- **Развертывание**: Docker и Docker Compose

## 📋 Предварительные требования

Перед запуском приложения убедитесь, что у вас установлено следующее:
- Python 3.10 или выше
- [wkhtmltopdf](https://wkhtmltopdf.org/downloads.html) (необходимо для конвертации в PDF)

## ⚙️ Установка и настройка

### Локальный запуск

1. **Клонирование репозитория**:
   ```bash
   git clone <repository-url>
   cd TerraData
   ```

2. **Создание и активация виртуального окружения**:
   ```bash
   python -m venv venv
   source venv/bin/activate  # Для Windows: venv\Scripts\activate
   ```

3. **Установка зависимостей**:
   ```bash
   pip install -r requirements.txt
   ```

4. **Запуск приложения**:
   ```bash
   python main.py
   ```
   API будет доступно по адресу `http://localhost:8000`.

## 🔌 API Эндпоинты

После запуска сервера вы можете получить доступ к интерактивной документации Swagger по адресу `/docs`.

### Данные Росреестра
| Эндпоинт | Метод | Описание |
| :--- | :--- | :--- |
| `/rosreestr/info/{cad_num}` | `GET` | Получение полной информации по кадастровому номеру |
| `/rosreestr/search-address` | `GET` | Поиск кадастровых номеров по адресу |

### Конвертер PDF
| Эндпоинт | Метод | Описание |
| :--- | :--- | :--- |
| `/converter/xml-to-pdf` | `POST` | Конвертация загруженного XML-файла в PDF |
